# vidiya
Website toko tas sederhana yang dibuat menggunakan HTML, CSS, dan JavaScript melalui Visual Studio Code. Website ini berisi katalog produk tas, informasi produk, metode pembayaran seperti OVO, DANA, GoPay, dan transfer bank, serta informasi alamat toko di Kabupaten Pemalang, Kecamatan Ulujami, Desa Limbangan.
